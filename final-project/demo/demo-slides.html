Which loan offer is actually cheapest
and can I afford it?

Four HKD 180,000 personal instalment-loan offers. Different nominal rates, arrangement fees, terms and repayment structures. A HKD 6,000 monthly cap.

Synthetic teaching data Inputs: offers CSV + borrower JSON Python standard library only Single agent

Why the shortcut fails

Nominal rates hide fees and term effects. A 24-month offer can be cheapest in total interest yet impossible to service. An equal-principal plan is front-loaded.

What we deliver

Exact amortisation schedules, IRR-based APR/EAR, an affordability verdict, an all-in ranking and an independent check record.

Live demonstration - single take. If recorded, label it as recorded.

Independent IRR

Limitations

Monthly instalments only. Nominal all-in cost is undiscounted. Fee-withholding is an assumption. Synthetic data, no real quotes. APR here is an IRR-based borrower cost, not a statutory disclosure figure. 83 checks on two small cases.

One-line takeaway: the lowest advertised rate is not the cheapest loan - a reproducible cash-flow calculation with an independent check makes that visible.
